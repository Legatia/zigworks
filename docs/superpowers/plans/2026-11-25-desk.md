# harness: the desk, harness's side and the page — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** harness serves the desk: entry by a one-time code and an in-memory session cookie, the desk page (avatar, chat for main and topics, Needs you, Topics, Lately, the status card, settings) and its API (turns, answers, history, a long-poll of events, the run view, seen, settings, voice, upload, speech); `state/desk.json` and a fixed `[apps] port`; `harness stop`, `harness autostart on|off`, `harness open`.

**Architecture:** Pure pieces in a new `deskwin.zig` (codes, sessions, cookies, the event feed and its long-poll, the per-conversation history, the spoken text, the state table, run labels, ETags, desk.json) and `autostart.zig` (LaunchAgent, XDG entry, Run value, where the desk app is). `appserver.zig` learns the desk's routes (`/alive`, `/enter`, `/desk`, `/desk/static/…`, `/desk/avatars/…`, `/desk/assets/…`, `/desk/apps/NAME`, `/desk/api/…`), cookies, larger bodies and files for those paths only, and the desk's CSP; it holds the codes and sessions and polls `state/open-request`. `core.zig` gets a `DeskWin` namespace (the API's answers) and a tee in front of the channel (every post also into the desk's history and feed); `agent.Run` gets a `live` hook (run start, end, helpers). The page is plain HTML, CSS and JS under `src/desk/`, embedded.

**Tech Stack:** Zig 0.17.1, std only; HTML, CSS, plain JS (ES modules, no build step); macOS, Linux, Windows.

**Spec:** `docs/superpowers/specs/2026-11-24-harness-desktop-app-design.md` (approved 2026-11-25, the 3D head). Binding: Intent, Goals, "What the apps design said", "The desktop app and getting in" (harness's side), The chat, Live updates, The side panel, The avatar (states, status card, the pack, serving, the module's interface), Speech, The look, Constraints, the Tests list. Not this plan's: the desk apps (`harness/desk-app/`, workflows: platform/desk-mac and the Windows session), the avatar module, the fit, `harness/src/avatar.zig`, `harness avatar check`, `harness/tools/`, the README's "Avatar packs" (platform/desk-avatar).

## Global Constraints

- Zig 0.17.1, std only on harness's side. The page: HTML, CSS, plain JS, no build step, embedded (`@embedFile`); fonts embedded as WOFF2 (Chakra Petch, JetBrains Mono, OFL, notices kept). No outside host anywhere.
- Copy (CLAUDE.md): plain labels, never slogans; what needs explaining sits behind a small "i" button with a bubble; risk and privacy disclosures (the upload's consent line, "Earlier messages aren't kept for private conversations.") stay inline. Page title "harness".
- The app server's rules hold: 127.0.0.1 only, Host and Origin checks, a CSP with every load on this server, shell paths refuse `Origin: null`. The new desk paths answer only to the session cookie.
- Entry: `state/open-request` (no secret) → `state/desk-code` (one-time, 60 s, used once, mode 0600, deleted when read or expired) → `GET /enter?code=…` → `Set-Cookie: harness_desk=…; Path=/; HttpOnly; SameSite=Strict` (no Expires), sessions in memory only. Nothing reusable on disk.
- Bodies: 1 MiB as today; 10 MB for `desk/api/voice` and `desk/api/upload` only. Files: 20 MB for `/desk/avatars/` and `/desk/assets/` only, with `Cache-Control: private, max-age=86400` and an ETag.
- Names: page `/desk`; `desk` joins `apps.reserved`; code names don't clash with core's `desk`, `appDesk`, `wfDesk` (new: `deskwin.zig`, `DeskWin`, `cfg.desk` for `[desk]`).
- Settings `[desk]`: `echo = on`, `avatar = butler`, `speak = off` (`off | browser | PROVIDER`), `speak_model = tts-1`, `speak_voice = alloy`. Written by write-then-reload (`mail.setKey`, `writeSetting`, `applySetup`), as `/persona` does.
- Private conversations' desk history is never written; history is in memory, 50 per conversation.
- Others build at the same time: edits to shared files small and local; never touch `desk/avatar.js`, `desk/fit.js`, `desk/vendor/` beyond the stand-ins named here, nor `avatar.zig`, `tools/`, `desk-app/`, workflows.
- Windows: paths joined with `std.fs.path.join`; listed dirs opened `.iterate = true`; no test reads the real clock where a fixture holds times.
- Baseline (9f1c725): measured at Task 0. From `harness/`: `zig build test --summary all --cache-dir ../.superpowers/cache > FILE 2>&1`; Debug and ReleaseSafe; smoke with and without HOMEMCP_BIN, CARCLOUD_BIN, CALMCP_BIN, MAILMCP_BIN; cross builds `zig build` and `zig build unit-build` for x86_64-windows, x86_64-linux-musl, aarch64-linux-musl. Known flake: core `each_of_these_asks` ("Busy" at reload).

## Review Focus

1. **A code raced or replayed** (the app reads the code; something else uses it first, or the same code twice, or after 60 s): only the first use within 60 s gets a session; the file is gone after use or expiry; a wrong code of the right length is refused in constant time (`a_code_works_once_and_expires`, Task 2; `enter_sets_a_session_cookie_once`, Task 3).
2. **A framed app reaching the desk** (an app's script fetches `/desk/api/send` with `Origin: null`, or with the cookie the browser would attach): refused before any desk call (`desk_paths_refuse_a_framed_app_and_need_the_cookie`, Task 3).
3. **A long-poll across a restart of harness or many events** (`after` from an earlier start, or older than the feed keeps): answered at once with `reset`, never a hang or a gap (`the_feed_answers_late_and_old_cursors_with_reset`, Task 2).
4. **A pack path trick** (`/desk/avatars/../config.ini`, `%2e%2e`, a link in `avatars/x/`, a 25 MB file, `upload?avatar=../x`): 404 or refused, nothing outside `avatars/` or `desk-assets/` read or written (`desk_files_are_served_with_caching_and_no_tricks`, Task 3; `upload_writes_only_into_the_avatars_folder`, Task 5).
5. **A private conversation on the desk**: its turns show while harness runs, its history is never filled from or written to disk, and the page says so inline (`private_desk_history_stays_in_memory`, Task 4).

### Task 2: deskwin.zig — the pure pieces

**Files:** create `deskwin.zig`; `main.zig` (test import).

**Produces:**
- `Codes`: `issue(c: *Codes, io, path) ![22]u8` (16 random bytes, base64url; the file written new, `util.private_file`, `CODE\n`), `take(c, io, path, given, now_ms) bool` (equal in constant time, unexpired, unused; deletes the file), `expire(c, io, path, now_ms)` (past 60 s: forgotten, file deleted). `code_ms = 60_000`.
- `Sessions`: `create(s, io) ![43]u8` (32 random bytes), `valid(s, token) bool`, at most 16 (the oldest goes). `cookie_name = "harness_desk"`, `cookieOf(header_value, name) ?[]const u8`, `setCookie(buf, token) []const u8` = `harness_desk=T; Path=/; HttpOnly; SameSite=Strict`.
- `Feed`: a ring of 512 events, each `{seq, json}` (owned); `push(f, kind: []const u8, fields_json: []const u8)` makes `{"seq":N,"type":"KIND",FIELDS}`; `since(f, a, after, wait_ms, stop) !Since` → `{ seq, events: []const []const u8, reset: bool }`: events after `after` at once; none: waits (condition, 100 ms slices for `stop`) up to `wait_ms`; `after` > last seq or older than the ring: `reset`. `json(a, Since)` → `{"seq":N,"events":[…]}` (`"reset":true` when so).
- `History`: per conversation (up to 64 conversations), the last 50 `Msg { id: u64, from: enum { you, harness }, text, at: i64, item: u64 = 0, urgent: bool = false, via: []const u8 = "" }`; `add(h, conv, msg) !u64` (ids count up across all), `list(h, a, conv) ![]Msg`, `find(h, a, id) ?struct{conv, msg}`; `msgJson(out, a, conv, msg)` with `"say"` (the spoken text) for harness's.
- `spoken(a, text) ![]const u8`: whole when ≤ 400 bytes; else the first two sentences (cut at `. `, `! `, `? ` or a line break) and " The rest is on screen." (the two kept ≤ 400 bytes, else cut at a word).
- `State = enum { urgent, needs, working, quiet, resting }`; `stateOf(f: Facts) State` with `Facts { urgent_items: usize, alerts: usize, open_items: usize, runs: usize, quiet: bool }` in the spec's order (speaking is the page's, between urgent and needs).
- `runLabel(a, by, text) ![]const u8`: `owner` → the first line of `text`, cut at 80 with "…"; `schedule:N` → "Routine: N"; `trigger:N` → "Trigger: N"; `workflow:N` → "Workflow: N"; `app:N` → "App: N"; else "Run: BY".
- `etag(data) [34]u8` (`"` + 32 hex of SHA-256 + `"`), `deskJson(a, binary, port, home, version) ![]const u8`, `validAvatar(name) bool` (a-z, 0-9, -, 1–32), `packFile(part) ?[]const u8` (still/closed → by magic, head → head.bin, eyes → eyes.png, eyemask → eyemask.png), `imageExt(data) ?[]const u8` ("jpg"/"png" by magic), `avatarIni(a, files)`.

- [ ] Tests: `a_code_works_once_and_expires` (taken once; second take false; a wrong code false; at 60 001 ms false and the file gone; file mode 0600 off Windows), `sessions_are_random_and_bounded`, `cookies_are_read_from_the_header` (`a=1; harness_desk=XYZ; b=2`, spaces, missing), `the_feed_answers_at_once_or_waits` (a push from another thread ends the wait), `the_feed_answers_late_and_old_cursors_with_reset`, `history_keeps_the_last_50_per_conversation`, `long_replies_speak_two_sentences`, `the_state_table` (each row of the spec's table, in order), `run_labels_name_who_started_it`, `desk_json_names_binary_port_home_version`, `pack_files_are_checked_by_magic`.

### Task 3: The app server's desk paths

**Files:** `appserver.zig`, `desk/` (stand-ins `avatar.js`, `fit.js`, `vendor/three.module.min.js`, a first `index.html`), tests.

**Interfaces:** `Options.desk: ?DeskOptions = null` with `{ home: []const u8 (DATA), state: []const u8 (DATA/state) }`. `Host.desk: ?*const fn (ctx, a, DeskCall) Answer = null`; `DeskCall { method, path (after "/desk/api/"), query, body, content_type, stop }`. `Server.feed: *deskwin.Feed` is the core's (passed in Options as `feed`), so the long-poll is answered by the host.

Routes (Host and Origin checks first, as today):
- `GET /alive` → 200, empty, `cache-control: no-store`.
- `GET /enter?code=C` → code taken: 303 to `/desk` with Set-Cookie; else 403 "This code was used or has expired. Open the desk again."
- Every `/desk…` path needs a valid session cookie, else 401 "Open the desk from the harness app." (`/desk/api/…`: JSON `{"error":"signed out"}`, the page's cue to send `{"reenter":true}`).
- `GET /desk` → the page; `GET /desk/static/F` → the embedded table `desk_files` (`index.html`, `desk.css`, `desk.js`, `avatar.js`, `fit.js`, `vendor/three.module.min.js`, `fonts/*.woff2`, `fonts/OFL-*.txt`).
- `GET /desk/avatars/NAME/F`, `GET /desk/assets/P` → files under DATA/avatars/NAME and DATA/desk-assets, each part checked (`apps.servableName` per part, no links), ≤ 20 MB (413 past it), `Cache-Control: private, max-age=86400`, `ETag`, `If-None-Match` → 304.
- `GET /desk/apps/NAME` → the shell page framing the app's `/a/TOKEN/` (as `/s/TOKEN/NAME`).
- `/desk/api/…` GET and POST → `Host.desk`; POST bodies ≤ 1 MiB, ≤ 10 MB for `voice` and `upload`.
- CSP for `/desk` and `/desk/static/`: `default-src 'none'; script-src O 'wasm-unsafe-eval'; style-src O; img-src O blob:; font-src O; media-src O blob:; connect-src O; worker-src 'none'; frame-src 'none'; object-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'` — confirmed against MediaPipe tasks-vision 0.10.14 (script-injected loader, `WebAssembly.instantiate`, no workers, no `new Function`).
- A poller thread (desk on): every 200 ms, `state/open-request` → deleted, a code issued to `state/desk-code`; codes expired.

- [ ] Tests: `alive_answers_and_nothing_else`, `enter_sets_a_session_cookie_once` (HttpOnly, SameSite=Strict, Path=/, no Expires; a second use 403; the code file gone; an open-request answered by a file within 2 s), `desk_paths_refuse_a_framed_app_and_need_the_cookie` (no cookie 401; `Origin: null` 403 with the cookie; another site 403; the fake host not called), `desk_page_and_static_files_with_their_csp`, `desk_files_are_served_with_caching_and_no_tricks` (ETag, 304, private max-age; `..`, `%2e%2e`, a link, a file over 20 MB), `desk_bodies_may_be_10_mb_for_voice_and_upload_only`.
