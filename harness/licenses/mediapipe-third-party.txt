Third-party code in MediaPipe's WebAssembly (desk-assets/mediapipe/wasm/)

MediaPipe tasks-vision 0.10.14's WebAssembly modules are built from
MediaPipe and the libraries it links. The modules name these (found in
their strings, 2026-11-25):

  TensorFlow Lite, Abseil, ruy, FlatBuffers,  Apache License 2.0
  gemmlowp                                    (the text in LICENSE-mediapipe.txt)
  OpenCV 4.9.0 (core, imgproc)                Apache License 2.0 (4.5.0 and later)
  XNNPACK                                     BSD 3-Clause, below
  Protocol Buffers                            BSD 3-Clause, below
  Eigen                                       Mozilla Public License 2.0, below
  Ooura's FFT (fft2d, in TensorFlow Lite)     its own terms, below
  Emscripten's runtime (the .js loaders)      MIT or University of
                                              Illinois/NCSA, below

XNNPACK is built with these, which the modules don't name:

  FP16, FXdiv                                 MIT, below
  pthreadpool, cpuinfo                        BSD 2-Clause, below

The modules are built from Google's own source tree (their paths start
third_party/), not from the published WORKSPACE, so the list is from the
modules themselves. Checked against the libraries MediaPipe v0.10.14's
WORKSPACE declares (2026-11-25): none besides these is named in either
module.
