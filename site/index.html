Small, fast tools that coding agents run on, written in Zig.

trigrep searches huge codebases in milliseconds and never misses a file you just saved. headterm lets an agent drive programs that need a real terminal. headsight lets an agent wait for something on screen or camera instead of taking screenshot after screenshot. All three are command-line tools.

$ trigrep install-rg-shim
$ trigrep -t c -C 2 'spin_lock_irqsave'

trigrep

Instead of grep and ripgrep on big repositories

Indexed code search with ripgrep’s flags and output. A file watcher keeps the index current, so a search always sees the edit you made a second ago.

headsight

Instead of screenshot after screenshot

One command that blocks until a window, the screen or the camera changes, goes still or shows some text, then prints one line and the path of a small crop.

trigrep

A trigram index narrows every search to the files that can match. On the Linux kernel that turns a 1.4 second scan into tens of milliseconds.

Same answers as ripgrep

Every benchmark search is diffed against ripgrep, line by line. The comparison script ships in the repository, so you can run it on your own code.

Patterns with no literal of three or more characters, like \d{4}-\d{2}-\d{2}, can’t use the index. They scan every file at about ripgrep’s speed.

scripts/compare.sh
$ compare.sh linux spin_lock_irqsave -C 2
same  94866 lines  [spin_lock_irqsave] -C 2
$ compare.sh linux 'EXPORT_SYMBOL\w*' -o -t c
same  40792 lines  [EXPORT_SYMBOL\w*] -o -t c
$ compare.sh linux '[α-ω]+'
same  90 lines  [[α-ω]+]
$ compare.sh linux 'TODO|FIXME|XXX'
same  22499 lines  [TODO|FIXME|XXX]

  • Never stale

    FSEvents or inotify tell trigrep what changed, and a cookie file proves every event arrived before it answers.

    trigrep watch

  • Branch switches in milliseconds

    Changed files go into a small delta index: 500 files in 84 ms, no full rebuild.

    trigrep index --update

  • ripgrep’s flags

    Types, globs, context lines, only-matching and the same JSON Lines format.

    trigrep -t rust -C 2 --json

  • Behind Claude Code’s Grep

    Answers as rg with identical output, and passes anything it can’t reproduce to ripgrep. Also an MCP server.

    trigrep install-rg-shim

headterm

Agents can run commands but not use them when a program wants a keyboard. headterm puts the program in a pseudo-terminal and gives the agent eyes and hands.

  1. Start a program

    headterm start py -- python3 -q

  2. Send keys

    Text, <Enter>, <C-c>, arrows, mouse clicks and drags.

    headterm send py 'print(2**10)' '<Enter>'

  3. Wait and read the screen

    For text, a regex, quiet output or exit. Then the screen comes back as plain text.

    headterm wait py --text 1024

  4. Close it

    Or let it go: idle sessions close themselves after an hour.

    headterm kill py
what the agent receives
>>> print(2**10)
1024
>>>
[headterm] py 60x6 cursor=2,4 running wait=ok(text) waited=0ms

  • One call per interaction

    Start a program, press keys, wait for text and get the final screen in a single command.

    headterm run --send Down Enter --wait-exit -- ./setup

  • Diffs, per agent

    Only the rows that changed since this agent last looked, even with several watching.

    --diff --client ID

  • Recordings

    Sessions saved as asciicast files, ready for asciinema play.

    --record run.cast

  • Tested on real programs

    vim, less, top, Python, curses menus and git add -p, on macOS and Linux.

    headterm mcp

headsight

An agent waiting for something visual takes a screenshot, sends it to the model, and repeats. headsight watches instead, on the Mac, and wakes the agent only when there is something to look at.

  • Wait for text

    Apple’s on-device text recognition runs on frames that changed.

    headsight wait --text "Done" --window Export

  • Wait until it settles

    Returns once nothing has changed for 800 ms, or the time you give.

    headsight wait --still --window Counter

  • See what changed

    Name a reference, make the change, then get a crop of every area that differs.

    headsight diff --since before
what the agent receives
diff since=before age=7s boxes=3
  box 368,192,544,96
  crop=…/headsight/9e59-1.png
  box 128,592,320,80
  crop=…/headsight/9e59-2.png
  box 464,384,208,80
  crop=…/headsight/9e59-3.png

  • Screen, window or camera

    A window is followed when it moves or is covered, and keeps working while the Mac is locked.

    --window TEXT --source camera

  • Ignores noise

    Title bars, recording indicators and camera sensor noise don’t count as changes.

    --ignore X,Y,W,H

  • Stays on the Mac

    Nothing is uploaded. Crops are capped at 1024 px and deleted after a day.

    headsight drop before

  • macOS only

    macOS 14 or later on Apple Silicon, with Screen Recording or Camera access for the app running the agent.

    headsight windows

Install

Single binaries for Linux (x86_64, arm64) and macOS (Apple Silicon). No runtime, nothing else to install. headsight is macOS only.

Download a release

With the binaries on your PATH, let Claude Code’s Grep use trigrep. The command prints the two settings to add.

trigrep install-rg-shim

Add this line to CLAUDE.md for headterm:

For programs that need a real terminal (TUI menus, wizards, passphrase prompts read from the TTY, full-screen apps), use the headterm CLI: `headterm run --send KEYS... --wait-text TEXT --screen -- CMD` plays keys and waits and prints the screen in one call; `headterm help run` has the details.

And this one for headsight:

To wait for something on screen or camera to change, settle, or show text, use the headsight CLI instead of repeated screenshots: `headsight wait --change|--still|--text TEXT [--window APP] [--region X,Y,W,H]` blocks and prints a crop path; `headsight help` has the details.

trigrep and headterm also run as MCP servers: claude mcp add --scope user trigrep -- trigrep mcp, and the same for headterm mcp.
