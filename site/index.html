Small, fast tools that coding agents run on, written in Zig.

trigrep searches huge codebases in milliseconds and never misses a file you just saved. headterm lets an agent drive programs that need a real terminal. Both are command-line tools and MCP servers.

$ claude mcp add --scope user trigrep -- trigrep mcp
$ trigrep -t c -C 2 'spin_lock_irqsave'

trigrep

Instead of grep and ripgrep on big repositories

Indexed code search with ripgrep’s flags and output. A file watcher keeps the index current, so a search always sees the edit you made a second ago.

headterm

Instead of tmux scripts and expect

A terminal an agent can use. It returns the screen as text, the rows that changed, and which text is highlighted, so menus, editors and installers stop being dead ends.

trigrep

A trigram index narrows every search to the files that can match. On the Linux kernel that turns a 1.4 second scan into tens of milliseconds.

Same answers as ripgrep

Every benchmark search is diffed against ripgrep, line by line. The comparison script ships in the repository, so you can run it on your own code.

Patterns with no literal of three or more characters, like \d{4}-\d{2}-\d{2}, can’t use the index. They scan every file at about ripgrep’s speed.

scripts/compare.sh
$ compare.sh linux spin_lock_irqsave -C 2
same  94866 lines  [spin_lock_irqsave] -C 2
$ compare.sh linux 'EXPORT_SYMBOL\w*' -o -t c
same  40792 lines  [EXPORT_SYMBOL\w*] -o -t c
$ compare.sh linux '[α-ω]+'
same  90 lines  [[α-ω]+]
$ compare.sh linux 'TODO|FIXME|XXX'
same  22499 lines  [TODO|FIXME|XXX]

  • Never stale

    FSEvents or inotify tell trigrep what changed, and a cookie file proves every event arrived before it answers.

    trigrep watch

  • Branch switches in milliseconds

    Changed files go into a small delta index: 500 files in 84 ms, no full rebuild.

    trigrep index --update

  • ripgrep’s flags

    Types, globs, context lines, only-matching and the same JSON Lines format.

    trigrep -t rust -C 2 --json

  • Built for agents

    An MCP server with search, index and status tools. Results are capped and say when they are.

    trigrep mcp

headterm

Agents can run commands but not use them when a program wants a keyboard. headterm puts the program in a pseudo-terminal and gives the agent eyes and hands.

  1. Start a program

    headterm start py -- python3 -q

  2. Send keys

    Text, <Enter>, <C-c>, arrows, mouse clicks and drags.

    headterm send py 'print(2**10)' '<Enter>'

  3. Wait and read the screen

    For text, a regex, quiet output or exit. Then the screen comes back as plain text.

    headterm wait py --text 1024

  4. Close it

    Or let it go: idle sessions close themselves after an hour.

    headterm kill py
what the agent receives
>>> print(2**10)
1024
>>>
[headterm] py 60x6 cursor=2,4 running wait=ok(text) waited=0ms

  • Sees highlights

    Inverse, bold and colours as runs per row, so the selected menu item is never a guess.

    --styles

  • Diffs, per agent

    Only the rows that changed since this agent last looked, even with several watching.

    --diff --client ID

  • Recordings

    Sessions saved as asciicast files, ready for asciinema play.

    --record run.cast

  • Tested on real programs

    vim, less, top, Python, curses menus and git add -p, on macOS and Linux.

    headterm mcp

Install

Single static binaries for Linux (x86_64, arm64) and macOS (Apple Silicon). No runtime, nothing else to install.

Download a release

With the binaries on your PATH:

claude mcp add --scope user trigrep -- trigrep mcp
claude mcp add --scope user headterm -- headterm mcp

With Zig 0.15.1:

git clone https://github.com/Legatia/zigworks
cd zigworks/trigrep && zig build -Doptimize=ReleaseFast
