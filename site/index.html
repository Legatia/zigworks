Small, fast tools that coding agents run on, written in Zig.

Two open-source command-line tools, each also an MCP server. trigrep searches large codebases in milliseconds and never misses a file you just saved. headterm lets an agent use programs that need a real terminal: editors, installers, REPLs, menus.

Download a release View the source

trigrep

Code search with an index, for repositories too big to grep on every question. Its output is the same as ripgrep's, but a search only reads the files that can match. A file watcher keeps the index current, so edits made a moment ago are always included.

Patterns with no literal text of three or more characters, such as \d{4}-\d{2}-\d{2}, can’t use the index and scan every file. There trigrep runs at about ripgrep’s speed.

  • ripgrep’s flags and output: -i -w -F -o -l -c, -A/-B/-C, -t rust, -g '*.ts', --json.
  • Unicode-aware regex: \w, \b, [α-ω] and case-insensitive non-English text.
  • After a branch switch, changed files are folded into the index in milliseconds, without a full rebuild.
  • MCP tools: trigrep_search, trigrep_index, trigrep_status.

headterm

A terminal for agents. It runs a program in a pseudo-terminal and returns the screen as text, the rows that changed since the agent last looked, and which text is highlighted. The agent sends keys and waits for text, a regular expression, quiet output, or the program to exit.

  • Tested with vim, less, top, Python, curses menus and git add -p.
  • Keys, mouse clicks and drags, bracketed paste.
  • Sessions can be recorded as asciicast files and replayed with asciinema play.
  • MCP tools for start, send (and wait in the same call), screen, wait, resize, list and kill. Idle sessions close after an hour.

Install

Download a binary for Linux (x86_64 or arm64, static) or macOS (Apple Silicon) from the releases page, put it on your PATH, and add it to Claude Code:

claude mcp add --scope user trigrep -- trigrep mcp
claude mcp add --scope user headterm -- headterm mcp

Or build from source with Zig 0.15.1:

git clone https://github.com/Legatia/zigworks
cd zigworks/trigrep && zig build -Doptimize=ReleaseFast

How they’re built

Dependencies
The Zig standard library and libc. Nothing else to install or audit.
Size
Single static binaries, about 500 to 700 KB.
Testing
Every commit is tested on Linux and macOS. trigrep’s output is checked line by line against ripgrep on the Linux kernel.
License
MIT. Source, issues and releases are on GitHub.
